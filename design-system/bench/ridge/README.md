# Регистрация Ridge при виртуализации

Из каталога `design-system` выполните `npm ci` и `npm run bench:ridge`. Запустите статический HTTP-сервер с корнем в `storybook-static`, откройте `/bench/ridge/` и нажмите «Запустить сравнение». Стенд также входит в сборку Storybook. Держите вкладку открытой, сохраняйте один размер окна в течение сравнения и сравнивайте результаты на одном устройстве.

## Нагрузка

Vite дважды собирает один TSX-файл в production. В одной сборке классы обнаруживает наблюдатель документа. Во второй плагин помечает JSX-элементы на этапе сборки и адаптер регистрирует поведение во время React commit. Обе сборки вызывают одинаковые `mountRidge` и `trackFocus`. Каждая серия стартует в новом iframe и проверяет наличие реальных рамок и работу фокуса.

| Окно из 20 000 записей | Что происходит за шаг |
| --- | --- |
| 128 строк в одном Ridge | 32 строки с input уходят и 32 приходят. Ridge остаётся смонтированным. |
| 48 узлов графа, из них 12 с вложенным полем | 6 узлов уходят и 6 приходят. Одновременно смонтировано 60 Ridge с трекерами фокуса. |

Окно перемещается детерминированно, со стабильными ключами. Раскладка всего графа, загрузка данных и обработка жестов в стенд не входят. На каждую комбинацию приходятся четыре серии с восемью шагами прогрева и сорока измеряемыми шагами. Порядок режимов чередуется по схеме AB, BA, BA, AB. Сценарий, который идёт первым, также чередуется.

## Метрики

- **Работа** — время от начала синхронного обновления React до чтения геометрии после контрольной точки микрозадач. Включает обновление DOM, регистрацию и очистку поведения и синхронную раскладку.
- **Кадр** — интервал между соседними отметками `requestAnimationFrame`. На него также влияют работа браузера после commit и частота обновления.
- **Callback наблюдателя** — среднее время внутри callback наблюдателя всего документа за шаг. При смене Ridge сюда входит подключение геометрии и фокуса. Этот столбец сам по себе не показывает экономию от трансформации.
- p50 и p95 вычисляются по 160 шагам каждого режима и сценария. В раскрывающемся блоке приведены также результаты отдельных серий и число записей о мутациях.

## Замер 24 ноября 2026

Chrome 156 на Linux, React и React DOM 18.3.1, production, 640 измеренных обновлений. В таблице указаны медиана и 95-й процентиль в миллисекундах.

| Сценарий | Работа, DOM | Работа, React | Кадр, DOM | Кадр, React |
| --- | ---: | ---: | ---: | ---: |
| Список | 6,4 / 11,9 | 6,0 / 10,8 | 200,0 / 216,7 | 199,9 / 216,6 |
| Граф | 42,2 / 64,5 | 49,7 / 79,1 | 200,0 / 216,6 | 199,9 / 216,7 |

В списке медиана React оказалась ниже в двух парах из четырёх. На графе медиана и p95 при регистрации через React выросли во всех четырёх парах. Медианы работы по парам в графе (DOM / React) составили 34,1 / 45,1, 54,7 / 60,7, 36,9 / 54,3 и 44,1 / 47,5 мс.

В списке глобальный callback получил 10 240 записей за 160 шагов и занимал в среднем 0,247 мс за шаг. В графе он получил 1 920 записей. При регистрации через React этот наблюдатель отсутствует. В обоих режимах обработка геометрии Ridge и локальные наблюдатели остаются активными.

Рабочий режим NEUI сохраняет обнаружение через DOM. Эксперимент с трансформером изолирован в этом каталоге. Интервал кадров в удалённом браузере был около 200 мс даже на лёгком списке. О плавности на экране телефона по нему судить нельзя.
