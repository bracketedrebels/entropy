# Trinet · Компоненты React

Первый срез дизайн-системы Entropy. В Storybook есть рабочая композиция «Настройки сводки», отдельные сценарии примитивов и переключатель светлой и графитовой тем. В истории «Настройки уведомлений» десять полей прототипа используют общий жёлоб, строки выбора, раскрытие и мета-действия. [Принципы взаимодействия](../docs/design-system/forms.md)

## Запуск

Из каталога `design-system` на Node 22.12+ выполните `npm ci` и `npm run storybook`. Каталог откроется на порту 6006. Команда `npm test` проверяет нативную активацию строки и сохранение состояния при раскрытии. `npm run typecheck` проверяет компоненты и примеры. `npm run build-storybook` создаёт переносимый статический каталог `storybook-static/`.

## Публикация

Workflow Component catalog проверяет pull request и прикладывает статическую сборку как артефакт `trinet-storybook`. После слияния в `master` каталог обновляется в `storybook/` ветки `gh-pages`. Для автоматического деплоя используется источник GitHub Actions в настройках Pages. Сборки графа и каталога запускаются по собственным путям, а публикации последовательно обновляют одну площадку.

## API

Импортируйте примитивы из `@trinet/design-system`. Оберните их в элемент с классом `tn-surface` и атрибутом `data-theme="dark"` или `data-theme="light"`. В Storybook эту обёртку и Ubuntu Light предоставляет каталог. Кнопка **Show code** под каждым примером показывает тот же TSX, который выполняется в превью, включая импорты, состояние и обработчики. У двух вариантов Row после компонента приведены параметры выбранного сценария.

### CSS API на Tailwind 4

Подключите Tailwind 4 к сборке приложения. В Vite для этого используется плагин `@tailwindcss/vite`. В основном CSS приложения импортируйте:

```css
@import "tailwindcss";
@import "@trinet/design-system/tailwind.css";
```

Примитивы попадают в слой `components`. Утилиты Tailwind можно передавать через `className`. Их значения берутся с текущей поверхности, поэтому один и тот же класс подходит для обеих тем.

| Что оформляем | Примеры утилит | Токены поверхности |
|---|---|---|
| Поверхность, шрифт и текст | `bg-surface`, `font-ui`, `text-ink`, `text-muted` | `--tn-bg`, `--tn-font`, `--tn-text`, `--tn-muted` |
| Жёлоб и фокус | `stroke-groove`, `stroke-lip`, `text-accent`, `bg-focus-core`, `bg-focus-halo`, `h-focus-band` | `--tn-channel`, `--tn-lip`, `--tn-copper`, `--tn-core`, `--tn-halo`, `--tn-band` |
| Отклик, метаданные и ошибки | `bg-ripple`, `bg-pill`, `text-danger` | `--tn-wave`, `--tn-pill-bg`, `--tn-danger` |
| Высота целей и скругления | `min-h-hit`, `min-h-action`, `min-h-choice`, `rounded-row`, `rounded-choice` | `--tn-hit`, `--tn-action-height`, `--tn-choice-height`, `--tn-row-radius`, `--tn-choice-radius` |

Например, класс `brand` на светлой поверхности задаёт общий акцент для жёлоба, выбранной точки и собственного текста с `text-accent`:

```css
.tn-surface.brand[data-theme="light"] {
  --tn-copper: #86421c;
}
```

В графитовой теме источник света и ореол настраиваются через `--tn-core` и `--tn-halo`. Для геометрии жёлоба задавайте радиус и высоту световой полосы в пикселях. Приложение с обычным CSS может подключить только `@trinet/design-system/styles.css` и использовать те же переменные.

### Компоненты

| Компонент | Параметры | Поведение |
|---|---|---|
| `Row` | `as` (div по умолчанию, также label и button), `leading`, `children`, `description`, `trailing` и атрибуты выбранного элемента | Вся строка опции активирует её нативный контрол. Для простого выбора передайте input внутрь label. Кнопка по умолчанию имеет type="button". Ripple обрезается по форме цели, очищается при отмене касания. |
| `Reveal` | `open`, `children`, опциональные `id`, `collapsed`, `returnFocusRef`, `followViewport` | Управляемый переход в потоке. Быстрое повторное нажатие разворачивает движение. Обе ветви сохраняют черновики. Неактивная ветвь получает inert и aria-hidden. Укажите реф на доступный триггер для возврата фокуса. Для явного раскрытия списка `followViewport` доводит поле до видимой границы и уступает управление ручному скроллу. |
| `Reveal.Group`, `Reveal.Item` | `open` для группы и для каждой строки, `followViewport` и `onCollapsed` на группе | В кратком и полном списке у каждой опции один Item с постоянным ключом. Уже видимые строки сохраняют место, остальные плавно раскрываются или сворачиваются. В `onCollapsed` можно переставить выбранные опции в начало, когда промежуточные строки уже скрыты. |
| `Ridge` | уникальный `id`, `label`, `children`, необязательные `header`, `meta` | В общей прокрутке верхняя и нижняя дуги прилипают к своим краям. В нижнем слоте первая капсула занимает правый угол. Общие параметры поверхности управляют материалом, светом и высотой индикатора. |
| `Field` | параметры Ridge плюс `description`, `error` | Связывает группу с подписью и пояснениями. Для одиночного контрола задайте `aria-labelledby={id + '-label'}`. Вспомогательные тексты имеют ID с окончаниями `-description` и `-error`. |
| `Pill.Action`, `Pill.Status` | `children`, атрибуты button или span. Action принимает ref | Действие доступно по Tab, информационная подпись пропускается. Доступное имя однотипного действия должно включать название поля. |
| `useFocusAnchor(ref, measure)` | реф на фокусируемый элемент, функция, возвращающая Y-координату в пикселях viewport | Заменяет центр строки собственным якорем. В примере редактор возвращает центр строки каретки. |

### Строка выбора

```tsx
<Row as="label" leading={<input type="checkbox" checked={selected} onChange={toggle} />}>
  Электронная почта
</Row>
```

### Условный ввод

```tsx
<button ref={trigger} type="button" aria-expanded={open} aria-controls="address-panel"
  onClick={() => setOpen(!open)}>Адрес доставки</button>
<Reveal id="address-panel" open={open} returnFocusRef={trigger}>
  <input aria-label="Адрес доставки" type="email" name="email" disabled={!open} />
</Reveal>
```

Видимость и участие в FormData — разные решения. Приложение отключает условный input при скрытии и хранит введённый текст до повторного открытия. Для информационной капсулы не нужен обработчик нажатия. Нативное значение, положение фокуса и кратковременный отклик на нажатие управляются отдельно.

## Форма уведомлений

Композиция находится в `stories/form/NotificationSettings.tsx`. Обычный выбор, справочник и редактор текста собраны из публичных примитивов. Состояние и связи полей принадлежат форме.

| Сценарий | Где попробовать |
|---|---|
| Один вариант | Частота, формат и действие при отсутствии событий. Для недоступного расписания показана причина. |
| Несколько вариантов | В каналах включите электронную почту. Появится адрес. Ошибка после выхода из редактора оставляет в силе последний корректный адрес. При отключении канала сохраняется черновик. |
| Большой справочник | Оба проектных поля ищут среди 144 позиций. Поиск закрепляется под заголовком. У формы один вертикальный скролл, в DOM остаются ближайшие строки, текущий фокус и краткая сводка. |
| Связь значений | «Первым в сводке» ставит проект первым в общем выборе. Если убрать его из сводки, приоритет сбросится. Капсула сброса позволяет вернуть предыдущее значение. |
| Текст | У темы лимит 120 символов, у вступления 300. Имя отправителя доступно для чтения и копирования. |

Выбор и тексты сохраняются в браузере. Адрес для доставки входит в данные формы при включённом почтовом канале. Ассистент даты и свайп удаления тега пока доступны в исходном прототипе.

## Сценарии

- В свёрнутых каналах нажмите «Входящие Trinet». Откроются шесть направлений с прежним выбором. Добавьте ещё два, сверните и откройте снова. Выбранные направления окажутся в начале.
- Во вступительном тексте переместите каретку между строками. Свет в жёлобе переместится вместе с ней. В режиме системных контрастных цветов фокус дополнительно обозначается рамкой. При остатке до 50 символов появится капсула счётчика.
- В истории Reveal наберите адрес, скройте поле и раскройте снова. Вернётся черновик. При включённом в системе уменьшении движения состояние меняется сразу.
- В истории Ridge прокрутите 24 строки в обе стороны. Верхний и нижний края ограничивают видимую часть поля. Переключатель «Тема» в панели Storybook меняет материал.
