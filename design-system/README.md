# NEUI · CSS и поведение

NEUI объединяет неоморфизм и UI. По-русски «не UI» подчёркивает внимание к UX. Форма уведомлений Trinet служит примером использования кита. Основной каталог открывается со страницы CSS API. У каждого примитива есть рабочие композиции и копируемая разметка. Раздел Vite описывает плагины, React знакомит с фабриками хуков, а в рецептах можно открыть исходники полей и полную форму. [Принципы взаимодействия](../docs/design-system/forms.md)

## Запуск

Из каталога `design-system` на Node 22.12+ выполните `npm ci` и `npm run dev:catalog`. Адрес локального каталога выведет Vite. Команда `npm run build:catalog` собирает сайт в `storybook-static/`. Для отдельного запуска исходных историй доступен `npm run storybook` (порт 6006).

`npm run typecheck` и `npm test` проверяют код кита. `npm run build-storybook` собирает публикацию целиком: сайт в корне, архив историй в `storybook/` и стенд замеров в `bench/ridge/`. Конфигурации примитивов находятся в `catalog/primitives.ts`, исходники рецептов подключаются напрямую из файлов через Vite `?raw`.

Стенд сравнения регистрации Ridge доступен по пути `/bench/ridge/` в статическом каталоге. [Сценарии и результаты замеров](bench/ridge/README.md)

## Публикация

Workflow Component catalog проверяет pull request и прикладывает статическую сборку как артефакт `trinet-storybook`. После слияния в `master` каталог обновляется в `storybook/` ветки `gh-pages`. Для автоматического деплоя используется источник GitHub Actions в настройках Pages. Сборки графа и каталога запускаются по собственным путям, а публикации последовательно обновляют одну площадку.

## API

Разместите нативные контролы внутри элемента с классом `neui-surface` и атрибутом `data-theme="dark"` или `data-theme="light"`. В Storybook эту обёртку и Ubuntu Light предоставляет каталог. Кнопка **Show code** под каждым примером показывает тот же TSX, который выполняется в превью, включая импорты, состояние и обработчики. У двух вариантов Row после компонента приведены параметры выбранного сценария.

### CSS API на Tailwind 4

В Vite 7 подключите адаптер NEUI рядом с Tailwind. Так настроен и этот Storybook.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'
import { neui } from '@neui/kit/vite'

export default defineConfig({ plugins: [tailwindcss(), neui()] })
```

В основном CSS приложения подключите тему, утилиты и стили NEUI:

```css
@import "tailwindcss";
@import "@neui/kit/tailwind.css";
```

Плагин подключает поведение ripple, жёлоба и трекера фокуса в каждой клиентской HTML-точке входа Vite. Клиент подхватывает статическую разметку, динамические классы и элементы из ленивых модулей. Частные классы с `@apply neui-ripple` используют тот же механизм. Исходные JSX и HTML-элементы остаются под контролем приложения.

Если HTML формирует сервер, укажите в конфигурации `neui({ clientEntry: 'src/entry-client.tsx' })`. Путь отсчитывается от Vite `root`. В этом режиме плагин дописывает статический импорт в указанный клиентский JS, TS, JSX или TSX модуль. Серверная сборка и исходники, запрошенные через `?raw`, сохраняют исходное содержимое. Этот же режим подходит для клиентского виджета с собственной точкой входа.

React-хуки доступны отдельно через `@neui/kit/react`. Для приложения на обычном DOM достаточно CSS и Vite-адаптера.

Примитивы попадают в слой `components`. Утилиты Tailwind можно передавать через `className`. Их значения берутся с текущей поверхности, поэтому один и тот же класс подходит для обеих тем.

| Что оформляем | Примеры утилит | Токены поверхности |
|---|---|---|
| Поверхность, шрифт и текст | `bg-surface`, `font-ui`, `text-ink`, `text-muted` | `--neui-bg`, `--neui-font`, `--neui-text`, `--neui-muted` |
| Жёлоб и фокус | `stroke-groove`, `stroke-lip`, `text-accent`, `bg-focus-core`, `bg-focus-halo`, `h-focus-band` | `--neui-channel`, `--neui-lip`, `--neui-copper`, `--neui-core`, `--neui-halo`, `--neui-band` |
| Отклик, метаданные и ошибки | `bg-ripple`, `bg-pill`, `text-danger` | `--neui-wave`, `--neui-pill-bg`, `--neui-danger` |
| Высота целей и скругления | `min-h-hit`, `min-h-action`, `min-h-choice`, `rounded-row`, `rounded-choice` | `--neui-hit`, `--neui-action-height`, `--neui-choice-height`, `--neui-row-radius`, `--neui-choice-radius` |

Например, класс `brand` на светлой поверхности задаёт общий акцент для жёлоба, выбранной точки и собственного текста с `text-accent`:

```css
.neui-surface.brand[data-theme="light"] {
  --neui-copper: #86421c;
}
```

В графитовой теме источник света и ореол настраиваются через `--neui-core` и `--neui-halo`. Геометрия жёлоба и высота световой полосы принимают CSS-длины. Приложение с обычным CSS может подключить только `@neui/kit/styles.css` и использовать те же переменные.

### Индикаторы выбора

`neui-check-radio` рисует круг диаметром 6 px, `neui-check-box` — квадрат того же размера. Оба класса задают только геометрию и материал. Семантику, управление с клавиатуры и источник значения выбирает приложение.

Яркостью управляет наследуемое числовое свойство `--neui-check-level`. При `0` видна пустая лунка, при `1` — выбранный индикатор темы. Дробные значения плавно смешивают эти состояния. Выше `1` усиливаются ядро и ореол. В светлой теме обычный выбор сохраняет плоский медный акцент. Длительность перехода задаёт `duration-*`.

```html
<label>
  <input type="checkbox" class="peer" />
  <span aria-hidden="true" class="neui-check-box duration-300 peer-checked:[--neui-check-level:1]"></span>
  Электронная почта
</label>
<span aria-hidden="true" class="before:neui-check-radio before:text-brand before:duration-300"
      style="--neui-check-level: 1.5"></span>
```

Цвет источника берётся из `currentColor`. Для своей палитры задайте `--color-brand` в Tailwind-теме приложения и примените `text-brand` непосредственно к индикатору, `before:text-brand` или `after:text-brand` — к соответствующему псевдоэлементу.

### Календарь

`useCalendar({ draft, onChange, locale, today? })` и `useCalendarGrid(calendar)` доступны через `@neui/kit/react`. Первый хук отвечает за редактирование, открытый сегмент, выбор, навигацию, сброс и отмену сброса. Второй возвращает данные для собственной разметки. `current.cells` содержит значение, подписи, признак выбора, сегодняшний день и стартовый столбец. `current.weekdays` задаёт порядок подписей. На каждом уровне `pages` содержит текущую страницу и доступных соседей. У дней шаг равен месяцу, у месяцев — году, у годов — 35 годам. `pageIndex` служит стабильным ключом страницы при листании. Порядок ячеек хронологический.

```tsx
import { useState } from 'react'
import { ru } from 'date-fns/locale/ru'
import { calendarDraft, useCalendar, useCalendarGrid } from '@neui/kit/react'

function Days() {
  const [draft, onChange] = useState(() => calendarDraft('2024-02-29'))
  const cal = useCalendar({ draft, onChange, locale: ru })
  const { current } = useCalendarGrid({ ...cal, part: 'day' })
  return <div className="neui-calendar-grid neui-calendar-days">
    {current.cells.map(cell => <button type="button" key={cell.value}
      style={{ gridColumnStart: cell.column }} aria-label={cell.accessibleLabel}
      aria-pressed={cell.selected} onClick={() => cal.choose('day', cell.value)}>
      {cell.label}
    </button>)}
  </div>
}
```

`neui-calendar-days`, `neui-calendar-months` и `neui-calendar-years` задают 7, 3 и 5 столбцов для `neui-calendar-grid`. Число столбцов можно изменить через `--neui-calendar-columns`. Роли, подписи, фокус, разметку и подсветку задаёт приложение. Рабочий пример находится в `stories/form/CalendarField.tsx` и `CalendarPanel.tsx`.

Календарная арифметика и названия дат используют `date-fns`. Локаль передаётся объектом, например `ru` или `enUS`. Порядок сегментов и разделители берутся из `Intl.DateTimeFormat`. Значение `cal.value` содержит дату без времени в формате `YYYY-MM-DD` либо `null`. Незавершённые сегменты доступны в `draft`. После выбора года открываются месяцы, после месяца — дни. Выбранный день остаётся виден до ручного сворачивания. В примере стрелки перемещают фокус, Page Up и Page Down листают страницы, Escape сворачивает поле.

Для периода используйте `useCalendarRange({ draft: { start, end }, onChange, locale, today })`. Каждая граница принимает тот же `CalendarDraft`, что и одиночная дата. `picker.endpoints.start.open('month')` открывает нужный сегмент. После выбора дня первой границы ассистент открывает дни второй в том же месяце. Обе границы включены. `picker.value` возвращает пару ISO-дат только для полного упорядоченного периода.

Передайте `{ ...picker.calendar, range: picker.range }` в `useCalendarGrid`. Для каждого дня доступны `inRange`, `rangeStart`, `rangeEnd` и `disabled`. Признаки `bandStart` и `bandEnd` позволяют скруглить полосу у конца недели или края месяца. Утилита `neui-calendar-range-day` рисует полосу на ячейках с соответствующими атрибутами `data-in-range`, `data-band-start` и `data-band-end`, равными `"true"`. Цвет задаёт `--neui-calendar-range-fill`. Для периода в один день обе границы совпадают. Пример с доступной разметкой, вводом с клавиатуры и сбросом находится в `stories/form/CalendarRangeField.tsx`.

### Кто владеет разметкой

Приложение выбирает HTML-элементы, их порядок, идентификаторы и доступные имена. Оформление публикуем как CSS. Поведение подключаем к существующим узлам. JSX в `recipes/` — редактируемые примеры композиции. У жёлоба можно заменить содержимое, подпись и SVG, а также добавить свои атрибуты на любую часть.

| Примитив | Разметка и CSS | Подключаемое поведение |
|---|---|---|
| Row | `neui-row` на label, button или другом контейнере. Прямые дети занимают именованные области `neui-row-area-leading`, `neui-row-area-content`, `neui-row-area-trailing`. Описание можно поместить рядом с текстом внутри content. | Нативный контрол управляет выбором. Для волны добавьте `neui-ripple` на саму цель с подключённым Vite-адаптером. |
| Pill | `neui-pill` на одном элементе. Для действия подойдёт `button type="button"`, для вычисленного статуса — `output`. CSS рисует фон внутри области нажатия. | Нативная активация и обработчик приложения. |
| Field | `fieldset` и `legend` группируют контролы. При отдельной видимой подписи укажите её ID через `aria-labelledby`, пояснения свяжите через `aria-describedby`. | Валидация и выбор момента показа ошибок принадлежат форме. |
| Раскрытие | `neui-collapse-block` для высоты, `neui-collapse-inline` для ширины. Внутренний элемент с `neui-reveal-clip` ограничивает содержимое. | Vite связывает условие JSX с временем жизни узла. `useRevealGroup` отдельно сопровождает раскрытие прокруткой и сообщает о завершении сворачивания. |
| Ridge | `neui-ridge` на контейнере. Содержимое принадлежит приложению, для подписи, закреплённого поиска и метаданных есть именованные слоты. | `neui-track-focus` публикует положение активной строки в CSS. Для каретки доступен измеритель `attachFocusAnchor` и его адаптер `useFocusAnchor`. |

```html

  <input class="neui-row-area-leading" type="checkbox" name="delivery" value="email" />
  <span class="neui-row-area-content">Электронная почта</span>
</label>
<button type="button" class="neui-pill">Сбросить</button>
```

### Появление и уход через Tailwind

С подключённым Vite-плагином `neui()` и стилями `@neui/kit/tailwind.css` задайте уход на том самом HTML-элементе, который удаляет React.

```tsx
{open && (
  <aside className="transition-opacity duration-300 starting:opacity-0 leaving:opacity-0 motion-reduce:transition-none">
    {hint}
  </aside>
)}

<ul>
  {channels.map(channel => (
    <li key={channel.id} className="transition-opacity duration-200 leaving:opacity-0 motion-reduce:transition-none">
      {channel.label}
    </li>
  ))}
</ul>
```

`starting:` задаёт начальный кадр при монтировании. `leaving:` применяется, когда условие стало ложным или из списка удалили ключ. Vite оборачивает только подходящее JSX-выражение. В DOM остаётся исходный элемент со своим `ref`. Во время ухода он получает `data-leaving="true"`, `inert` и `aria-hidden`. Браузер проигрывает CSS-переходы с заданными свойствами, задержками и кривыми. После завершения последнего перехода корневого элемента React его размонтирует. Если переходов нет, размонтирование происходит сразу. При быстром возврате ключа до завершения ухода тот же DOM-узел продолжает переход из текущего состояния.

Поддерживаются непосредственные JSX-потомки и корневое возвращаемое выражение именованного компонента: `&&`, тернарное выражение с `null` или `false` и прямой `.map()` с устойчивым `key`. Укажите литерал класса на корневом HTML-элементе. Класс, целиком собранный в рантайме, маркер внутри дочернего компонента или уход родителя вместе со всей веткой лежат за пределами этого преобразования. При смене двух веток одного типа задайте им разные ключи, если требуется анимировать замену. Отключить преобразование можно через `neui({ leaving: false })`.

#### Свои классы с `@apply`

```css
@utility disclosure { @apply neui-collapse-block; }
.digest-address { @apply disclosure; }
```

```tsx
{open && (
  <div className="digest-address">
    <div className="neui-reveal-clip">
      <input value={draft} onChange={e => setDraft(e.target.value)} />
    </div>
  </div>
)}
```

Базовые классы раскрывают одну дорожку grid по вертикали (`neui-collapse-block`) или горизонтали (`neui-collapse-inline`). У каждой дорожки один прямой потомок. Контент сохраняет естественный размер, а внешний узел обрезает его по анимируемой границе и плавно меняет прозрачность. Общая длительность задаётся через `--neui-disclosure-duration` (240 мс), кривая через `--neui-disclosure-ease` (`ease-in-out`). На элементе можно указать `duration-500`, `ease-out` и `delay-75`. При уменьшенном движении оба пресета сразу меняют состояние.

Vite до обработки JSX строит индекс связей между `@utility`, `@apply` и обычными именованными классами. Он проходит по цепочкам через локальные CSS-импорты и `@reference`. Исходные CSS-правила со всеми вариантами компилирует Tailwind. Клиент получает границу только у подходящего условия или списка. Имена классов и таблица связей для этого в браузере не требуются. В режиме разработки изменение состава таких классов обновляет модули JSX.

Обычный `neui()` уже включает обработку. Для отдельного подключения есть `neuiLeaving({ styles: ['src/app.css'] })` из `@neui/kit/vite`. У полного плагина тот же список задаётся через `neui({ leavingStyles: ['src/app.css'] })`. По умолчанию индексируются CSS-файлы проекта, кроме зависимостей и каталогов сборки, плюс CSS, доступный по импортам. Для монорепозитория или нескольких независимых тем укажите входные таблицы стилей явно. Предусмотрены глобальные простые имена классов. Локальные имена CSS Modules, селекторы потомков и имена, целиком собранные в JS, требуют явного литерала `leaving:` на уходящем узле.

Черновик, значение и выбор живут выше условной ветки — например, в состоянии формы. При полном закрытии поле размонтируется, при открытии новый узел получает сохранённое значение. До окончания ухода быстрое повторное открытие сохраняет тот же узел. Возврат клавиатурного фокуса, доведение панели до границы viewport и модель отправляемых данных остаются отдельными задачами. Для формы с нативной отправкой учитывайте, что `inert` исключает взаимодействие, но само по себе не выключает отправку значения во время анимации.

В Storybook история «Условный адрес» демонстрирует управляемый черновик, «Уход элемента» — удаление с ключами. В «Замер кадров» одни и те же 64 строки трижды переключаются в каждой серии, скрывается половина. После прогрева четыре серии чередуются для распознавания при сборке и для контрольного поиска в готовом наборе имён при рендере. Счётчик показывает проверки имён классов за одну серию. Состояние DOM измеряется после завершения последнего ухода.

Контрольный прогон production Storybook в Chromium 141, окно 412 × 915 CSS px, 60 Гц в покое. В обычном режиме сборочный вариант показал 60,0 FPS, поиск в рантайме — 58,0 FPS. С эмуляцией четырёхкратного замедления CPU оба показали 60,0 FPS. Во всех четырёх замерах p95 времени кадра составил 16,7 мс. Оба оставили 32 строки в DOM. В каждой серии Vite устранил все 192 проверки имени класса в браузере. По этим замерам устойчивого выигрыша в FPS установить нельзя.

### Жизненный цикл поведения

`prepareBehavior(attach)` вызывается один раз на уровне модуля. Он возвращает React-хук со стабильным callback-ref. Каждый экземпляр хука подключает поведение к своему узлу и вызывает cleanup при замене узла или размонтировании. Статическую конфигурацию можно замкнуть в `attach`. Изменяемое состояние передавайте в обычный хук, как `open` в `useReveal`.

В обычном DOM функции `attachRidge` и `attachFocusAnchor` доступны через `@neui/kit/dom`.

### Иконки и переходы

Каталог подключает самостоятельный пакет NEUIcon. Утилиты `neuicon-*` рисуют SVG-маски на элементе, в `::before` и в `::after`. Обычным растворением и специальным переходом бирки в корзину управляет `--neuicon-progress`. В Storybook откройте «Примитивы → Icon» и потяните ползунок. Подключение Vite, Tailwind и настройка числа кадров описаны в [NEUIcon](./neuicon/README.md).

### Ripple

С Vite-адаптером достаточно указать класс на интерактивном элементе. При интеграции с другим сборщиком доступен явный импорт `@neui/kit/ripple` из клиентской точки входа.

```html
<button type="button" class="neui-row neui-ripple">
  <span class="neui-row-area-content">Предпросмотр</span>
</button>
```

Делегирование событий работает и для добавленных позже строк. При нажатии волна начинается в точке касания. При активации с клавиатуры она начинается у маркера или в центре. У каждого нажатия свой центр и свой ход волны. Тёплый золотистый свет сверху ложится на обращённый к нему склон. Мягкая нейтральная тень на противоположном склоне плавно сходит на нет. При повторном нажатии гребни могут пересекаться. По мере затухания гребень становится ниже, а его склоны расходятся по обе стороны от вершины. При половинной амплитуде их ширина возрастает в полтора раза. У дальнего угла рельеф исчезает, в том числе при удержании пальца. Начало прокрутки отменяет волну текущего касания. Параметры темы и анимации задаются в CSS.

| Переменная | Значение |
|---|---|
| `--neui-ripple-progress` | Прогресс от 0 до 1. При 1 радиус достигает самого далёкого угла. |
| `--neui-ripple-x`, `--neui-ripple-y` | Координаты центра в процентах, по умолчанию 50% и 50%. |
| `--neui-wave-highlight`, `--neui-wave-shadow` | Блик и тень гребня. В светлой теме блик цвета шампанского, в графитовой — приглушённого золота. |
| `--neui-ripple-duration`, `--neui-ripple-fade` | Рост за 800 мс с `ease-out`. Затухание занимает последние 80% времени роста. Его можно задать явно, например `650ms`. При уменьшенном движении волна пропускается. |

Класс Tailwind на самой цели задаёт длительность роста, например `class="neui-ripple duration-500"` или `duration-[1250ms]`. Активная утилита имеет приоритет над `--neui-ripple-duration`. Длительность затухания регулируется отдельно.

Делегат берёт длительности из CSS. Web Animations интерполирует прогресс и амплитуду каждой волны независимо. Все волны рисуются в одном псевдоэлементе. Для ручного предпросмотра задайте `--neui-ripple-progress: .5` на элементе с классом `neui-ripple`. Paint Worklet рисует склоны каждого гребня. При отсутствии API или запрете загрузки два смещённых радиальных градиента передают свет и тень.

### Фокус

`neui-focus` отмечает поверхность, пока внутри неё находится фокус. Тема задаёт её вид токеном `--neui-focus-fill`. По умолчанию поверхность проявляется ровным матовым тоном от точки нажатия. Токен принимает цвет или градиент.

```html
<label class="neui-row neui-focus neui-ripple duration-800 ease-out">
  <input class="neui-row-area-content" aria-label="Имя отправителя" />
</label>
```

Для кнопки добавьте `neui-focus` на саму кнопку, для `input` или `textarea` — на обёртку с радиусом зоны ввода. Фокус занимает её `::before`. Отдельный класс `neui-ripple` добавляет гребень в `::after`. Если оба класса на одной поверхности, тон и гребень получают общую точку касания и один прогресс. По умолчанию движение занимает 800 мс с `ease-out`. Значения для темы задают `--neui-travel-duration` и `--neui-travel-easing`. Классы Tailwind `duration-*` и `ease-*` на самой поверхности переопределяют их и при раздельном использовании.

При повторном нажатии новая волна проходит поверх уже проявленного тона. При фокусе с клавиатуры или из кода и при уменьшенном движении тон виден целиком сразу. При потере фокуса он плавно гаснет. В режиме принудительных цветов фокус обозначает системный контур.

### Горизонтальный свайп

Класс `neui-swipe-right` на строке включает жест. В самой строке разместите содержимое и отдельную кнопку действия. Обработчик обычного `click` на этой кнопке изменяет данные приложения. Vite подключает делегат один раз. Для другого сборщика импортируйте `@neui/kit/swipe` в клиентской точке входа.

```tsx
<div className="neui-swipe-right neui-focus neui-ripple" data-neui-swipe-open={open}>
  <button type="button" className="neui-swipe-content" aria-expanded={open}
    onClick={() => setOpen(!open)}>{tag}</button>
  <button type="button" className="neui-swipe-action" tabIndex={open ? 0 : -1}
    aria-hidden={!open} onClick={() => remove(tag)}>Удалить</button>
</div>
```

Три структурных класса указываются на самих DOM-элементах. Рантайм измеряет ширину кнопки при начале жеста. Прогресс `--neui-swipe-progress` растёт от 0 до 1. После порога `--neui-swipe-tension` управляет упругим ходом до 32 px. Отпускание за порогом активирует кнопку один раз. Возврат до порога, отмена касания или вертикальная прокрутка сохраняют значение. Приложение может раскрыть действие через `data-neui-swipe-open` и вызвать ту же кнопку мышью или с клавиатуры.

В Storybook «Примитивы → Swipe» показывает поле тегов. Визуальная подсказка использует тот же прогресс, её первый показ запоминается в `sessionStorage` демонстрационного приложения. Способ хранения подсказок выбирает потребитель кита.

### Контракт жёлоба

На поверхности NEUI добавьте класс жёлоба на обычный `div` или `section`. Этот HTML работает с Vite-конфигурацией выше и сохраняет нативную связь подписи с полем.

```html
<section class="neui-ridge neui-track-focus neui-ridge-inset-[12px]">
  <label slot="label" for="sender">Имя отправителя</label>
  <div class="neui-row">
    <input id="sender" name="sender" class="neui-row-area-content" />
  </div>
</section>
```

- `neui-ridge` рисует непрерывный жёлоб с двумя липкими краями. Подпись в слоте `label` открывает линию на уровне baseline. Без подписи верхняя дуга замыкается. Содержимое без атрибута `slot` занимает тело. Слоты `header` и `meta` принимают соответственно липкий поиск и нижние мета-действия. Размещайте эти слоты на прямых детях контейнера.
- `neui-track-focus` можно поставить на любой отдельный контейнер. Он публикует `--neui-focus-active` (0 или 1) и `--neui-focus-y` (расстояние от верхней границы контейнера до центра фокуса). Ближайшая строка, pill или элемент с `neui-focus-anchor` задаёт центр. Для редактора с кареткой `attachFocusAnchor(element, measure)` принимает функцию, возвращающую вертикальную координату во viewport. При вложении фокус принадлежит ближайшему трекеру. Добавьте к внешнему трекеру класс `neui-track-focus-within`, чтобы он также подсвечивал положение фокуса внутри вложенных полей.
- Для настройки доступны `neui-ridge-radius-[1.5rem]` (радиус внутренней строки), `neui-ridge-inset-[12px]` и `neui-focus-band-[32px]`. Им соответствуют `--neui-row-radius`, `--neui-inset` и `--neui-band`. Отступы липких краёв задают `--neui-pin-top` и `--neui-pin-bottom`. Высота световой полосы по умолчанию 24 px в светлой теме и 64 px в графитовой.
- `--neui-ridge-depth` проявляет материал желоба от 0 (плоско) до 1 (обычная глубина). У кромок меняются видимость и расстояние между тенью и бликом. Размер поля и положение содержимого сохраняются.
- `--neui-focus-strength` управляет светом при реальном фокусе. При 0 свет погашен, 0.5 даёт половину непрозрачности, 1 воспроизводит обычный свет. Выше 1 в графитовой теме появляется мягкий ореол. В светлой теме насыщенность медного штриха достигает максимума при 1. Оба параметра по умолчанию равны 1. Они независимы и анимируются, например `neui-ridge-depth-0 focus-within:neui-ridge-depth-1 neui-focus-strength-[1.8] duration-300`.
- Два класса подключения указывайте буквально в HTML, JSX или шаблоне Vue. Их можно добавлять и снимать динамически. Модификаторы Tailwind и `@apply` подходят для размеров и цветов.

Vite подключает клиент один раз на документ. Он создаёт декоративную рамку в открытом Shadow DOM. Подпись, контролы и действия остаются в исходном DOM, со своими обработчиками и связями формы. Рамку можно стилизовать через `::part(head)`, `::part(foot)`, `::part(body)`, `::part(caption)`, `::part(header)`, `::part(meta)`, `::part(upper)`, `::part(walls)`, `::part(base)`, `::part(cut)`, `::part(lip)`, `::part(floor)` и `::part(light)`. Для нативного `fieldset` или компонента со своим shadow root используйте внешний контейнер. Полный авторский каркас из `recipes/LegacyRidge.tsx` можно также оставить в обычном DOM. Класс `neui-ridge` подключит геометрию к его структурным классам.

Для существующих приложений пакет по-прежнему экспортирует ранние JSX-обёртки Row, Pill, Field, Reveal и Ridge. Новые композиции в каталоге используют классы, хуки и открытые рецепты.

### Зерно страницы

Добавьте `neui-grain` на `<html>`, чтобы включить один слой по всей странице. `--neui-grain-opacity` задаёт его интенсивность (по умолчанию `0.028`). Монохромная плитка содержит поровну светлых и тёмных пикселей. Текстура смешивается с материалом в режиме `overlay` и прокручивается вместе со страницей. Браузер перемещает её при скролле самостоятельно. На витрине слой можно сравнить в карточке Surface кнопкой «Зерно страницы».

При подключении `neui()` Vite автоматически подключает синхронизацию с масштабом браузера, плотностью экрана и увеличением двумя пальцами. Для самостоятельного подключения укажите класс на корне HTML и импортируйте `@neui/kit/grain` в браузерной точке входа. Слой пропускает нажатия и скрывается при печати и в режиме принудительных цветов.

### Рельеф поверхности

У `neui-relief` одна знаковая длина `--neui-depth`. Положительное значение поднимает контур, отрицательное углубляет его, при нуле поверхность плоская. По умолчанию глубина равна 8 px. Свет падает вертикально сверху. У самой кромки блик и тень плотнее, а дальше от контура плавно ослабевают.

Светотень лицевой поверхности входит в `neui-relief`. У поднятой плитки середина слегка вогнута. При погружении верхняя стенка углубления даёт узкую тень, а выпуклая площадка чуть дальше от края ловит свет. Обе части рельефа плавно сходят на нет при нулевой глубине.

Рельеф задаёт профиль углов через `corner-shape: squircle`. Укажите радиус классом `rounded-*` в зависимости от размера элемента. Браузеры с поддержкой `corner-shape` проводят тени по этой кривой, остальные используют скругление от `border-radius`.

```html
<button class="neui-relief neui-depth-4 active:-neui-depth-4 duration-300 rounded-3xl">
  Сводка
</button>
```

Ступени глубины — 0, 2, 4, 8, 12 и 16 px. Поддерживаются отрицательные классы и произвольные длины, например `-neui-depth-4` и `neui-depth-[-2.5px]`. Переход через ноль учитывает `duration-*`, `ease-*` и настройку уменьшенного движения. Цвета можно переопределить через `--neui-relief-light` и `--neui-relief-shade`.

Прежние классы `neui-extruded` и `neui-intruded` дают начальные значения +8 и −8 px. При явно заданной глубине действует её знак. Для прежнего сочетания `neui-intruded neui-depth-4` используйте `neui-relief -neui-depth-4`, чтобы сохранить углубление.

Плагин входит в `@neui/kit/tailwind.css`. Для отдельного подключения добавьте `@plugin "@neui/kit/relief";` в точку входа Tailwind. Тени рисует CSS на самом элементе. Родитель с `overflow: hidden` или `clip` обрежет внешнюю тень у своего края. Оставьте внутри запас под тень или перенесите обрезку на дочерний элемент.

## Форма уведомлений

Композиция находится в `stories/form/NotificationSettings.tsx`. Обычный выбор, справочник и редактор текста собраны из публичных примитивов. Состояние и связи полей принадлежат форме.

| Сценарий | Где попробовать |
|---|---|
| Один вариант | Частота, формат и действие при отсутствии событий. Для недоступного расписания показана причина. |
| Несколько вариантов | В каналах включите электронную почту. Появится адрес. Ошибка после выхода из редактора оставляет в силе последний корректный адрес. При отключении канала сохраняется черновик. |
| Большой справочник | Оба проектных поля ищут среди 144 позиций. Поиск закрепляется под заголовком. У формы один вертикальный скролл, в DOM остаются ближайшие строки, текущий фокус и краткая сводка. |
| Связь значений | «Первым в сводке» ставит проект первым в общем выборе. Если убрать его из сводки, приоритет сбросится. Капсула сброса позволяет вернуть предыдущее значение. |
| Текст | У темы лимит 120 символов, у вступления 300. Имя отправителя доступно для чтения и копирования. |

Выбор и тексты сохраняются в браузере. Адрес для доставки входит в данные формы при включённом почтовом канале. Теги сводки сохраняются в порядке отображения. Незавершённый текст тега сохраняется как черновик.

## Сценарии

- В свёрнутых каналах нажмите «Входящие Trinet». Откроются шесть направлений с прежним выбором. Добавьте ещё два, сверните и откройте снова. Выбранные направления окажутся в начале.
- Во вступительном тексте переместите каретку между строками. Свет в жёлобе переместится вместе с ней. В режиме системных контрастных цветов фокус дополнительно обозначается рамкой. При остатке до 50 символов появится капсула счётчика.
- В истории Reveal наберите адрес, скройте поле и раскройте снова. Вернётся черновик. При включённом в системе уменьшении движения состояние меняется сразу.
- В истории Ridge прокрутите 24 строки в обе стороны. Верхний и нижний края ограничивают видимую часть поля. Переключатель «Тема» в панели Storybook меняет материал.

### Числовая шкала и последовательность значений

`neui-range` оформляет нативный `input[type=range]`. Атрибуты `min`, `max` и `step` задают допустимые позиции. Браузер обрабатывает перетаскивание и клавиши. Для делений поместите рядом собственный элемент с классом `neui-range-ticks` и по дочернему элементу на отметку. Общий предок может задавать `--neui-range-thumb` для изменения диаметра бегунка и отступа крайних отметок. Пример с дробным шагом находится в Storybook → Range.

В форме «Настройки сводки» у поля интервала есть свободный текстовый черновик, последнее применённое число и шкала, которая раскрывается при фокусе. Кнопка «Свернуть» рядом со значением и клавиша Escape возвращают к вводу. Разбор текста и отображение ошибки принадлежат обработчику формы. У поля порядка доставки приложение хранит стабильный ключ каждого вхождения для перестановки и удаления свайпом, а в данные записывает массив каналов в указанном порядке, включая повторы.

Утилита `neui-divider` оформляет короткий центрированный желоб на обычном `<hr>`. Длину задаёт `--neui-divider-size` (по умолчанию 25%). В форме сводки он разделяет порядок попыток доставки и каналы, доступные для добавления.
