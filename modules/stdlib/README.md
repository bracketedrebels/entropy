# stdlib

Базовый модуль Entropy, namespace `std`. В одной папке находятся контракт,
реализация, генератор, зависимости и проверки.

| Файл | Назначение |
| --- | --- |
| `module.ent` | Типы Stream, Result, Schema и нативные элементы |
| `runtime.mjs` | Реализация JS: RxJS, Ramda, AJV и именованные кортежи |
| `nodejs.mbt` | MoonBit-генератор импортов и bindings для Node.js |
| `package.json` | npm-зависимости и секция `entropy` с локальными путями |
| `moon.pkg` | Зависимость генератора от общего контракта backend |
| `test/runtime.test.mjs` | Проверки кодеков, кортежей и RxJS-операторов |

Подключение в manifest проекта: `"modules": ["path/to/stdlib/package.json"]`.
Загрузчик читает `entropy.source` и `entropy.platforms.nodejs.runtime` относительно
этого package.json. Для пользователя языка публичные имена остаются `std.map`,
`std.join`, `std.constant` и т. д. Перемещение всей папки не меняет её внутренние
пути. Пакет пока приватный; установка из registry не входит в M1.

Генератор экспортирует `nodejs(runtime_path) -> Module`: получает разрешённый
путь импорта и возвращает описание JS backend. Он также предоставляет intrinsics
кортежей, проекций и schema-кодека. Ядро знает назначение этих операций, но не
содержит их реализацию и не знает имён файлов stdlib.

`json.encode` объявляет в binding требование `json_input`. Компилятор проверяет
сигнатуру `(fn (a) JSON)` и переносит ограничение JsonEncodable через подграфы.
Это статическое требование; проверка значений JSON остаётся в AJV-кодеке.

Константа-исток `std.constant` использует RxJS `of`: одна эмиссия и завершение.
`map` и `switchMap` делегируют подписки и отмену соответствующим операторам RxJS.
Валидация возвращает Result, не приводит типы, не добавляет defaults и не удаляет
лишние поля. Поддерживаемый компилятором Draft 7 — строки и закрытые объекты.

Из корня репозитория после `npm ci`:

```sh
npm test --workspace @entropy/stdlib
```

Общая сборка `npm test` включает эти тесты. Проверки вывода типов и компиляции
композиции остаются у компилятора и в интеграционных тестах.
